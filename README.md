"The Bubble That Caught a Rainbow": a golden retriever puppy mid-leap in a sunflower meadow at golden hour, front paws reaching for one giant soap bubble — and inside the bubble ride a tiny rainbow and a small smiling sun. One specific, warm moment of joy, painted to make the AI judge happy. `main.ts` (Node 22, standard library only) checks the picture against the bounty gate — a whole PNG or JPEG, at most 1 MiB and 1024×1024 pixels — and writes it byte for byte to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
